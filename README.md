# Roof Estimator

A configuration-driven roofing cost estimator built with React, Node.js, Express and MongoDB.

## Features

- Configuration-driven estimator
- Dynamic questions from MongoDB
- Server-side estimate calculation
- Contact/lead capture
- Admin authentication
- Admin dashboard
- Editable business configuration
- Editable pricing modifiers
- Editable estimator questions
- Lead management

## Tech Stack

### Frontend
- React
- JavaScript
- CSS
- Fetch API

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
